# Análisis Estadístico de Patrones de Clientes - Megaline

## 🎯 Objetivo
El objetivo de este proyecto es analizar el comportamiento de los clientes de la empresa de telecomunicaciones Megaline para determinar cuál de los planes de tarifas genera más ingresos y ajustar el presupuesto de publicidad.

## 🛠️ Herramientas utilizadas
* Python
* Pandas y NumPy (procesamiento de datos)
* Matplotlib y Seaborn (visualización de gráficos)
* Jupyter Notebooks / Megaline Platform

## 📊 Metodología y Pasos del Proyecto
1. **Carga y Limpieza:** Corrección de tipos de datos y manejo de valores ausentes.
2. **Agrupación de datos:** Consolidación de llamadas, mensajes y consumo de internet por usuario mensual.
3. **Análisis de Outliers:** Identificación de valores extremos usando el método IQR y Boxplots.
4. **Prueba de Hipótesis:** Análisis estadístico para comparar los ingresos entre planes y regiones.

## 🚀 Cómo ejecutar el proyecto
1. Clona este repositorio o descarga el archivo `.ipynb`.
2. Asegúrate de tener instaladas las librerías `pandas`, `seaborn` y `matplotlib`.
3. Abre el cuaderno en Jupyter y ejecuta todas las celdas en orden.
